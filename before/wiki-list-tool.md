# Wiki List tool

The Wiki List tool can be useful for preparing and organising lists of people, organisations, subjects, and other entities connected to the conference.

Before the event, use lists to identify:

Speakers.
Panellists.
Researchers.
Organisations.
Conference partners.
Topics discussed at the event.
Existing Wikipedia articles.
Existing Wikidata items.
Gaps where information is missing.

These lists can become a practical work queue for Wikimedia contributors.

Where possible, link each person or organisation to their existing Wikipedia and Wikidata records. This makes it easier to identify what information already exists and where improvements are needed.
