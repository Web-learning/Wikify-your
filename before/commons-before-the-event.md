# Commons before the event

Wikimedia Commons can provide a lasting visual record of the conference.

Before the event, check whether there is already a Commons category for:

The conference.
Previous editions.
The venue.
The organising organisation.

If appropriate, create a category for the new event and establish a clear naming convention.

Think about what photographs would be useful:

Speakers giving presentations.
Panels and discussions.
The conference venue.
Posters and displays.
Publicly visible conference materials.
Group photographs where appropriate.
Wikimedia activities taking place at the event.

If photography permissions or restrictions apply, establish these with the organisers in advance.
